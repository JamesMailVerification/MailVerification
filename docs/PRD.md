## 2. 문제 정의

업무 담당자는 매일 많은 이메일을 처리하는 과정에서 일정과 답변 기한을 직접 확인하고 관리해야 하기 때문에 중요한 업무를 놓치거나 기한을 넘겨 원하는 업무 성과를 얻지 못한다.

## 3. 제품 목표

사용자가 이메일을 일일이 읽고 일정을 직접 입력하지 않아도 다음 업무를 수행할 수 있도록 한다.

- 이메일에서 일정과 답변 기한을 자동으로 찾는다.
- 추출한 내용을 일정 후보로 보여준다.
- 사용자가 확인한 일정만 캘린더에 등록한다.
- 마감 3일 전부터 매일 오전 9시에 알림을 제공한다.
- 오늘 처리해야 할 일정과 회신 업무를 한 화면에 보여준다.

## 4. 핵심 사용자

### 4.1 Primary User

- 회사 대표
- 프로젝트 매니저
- 영업 담당자
- 해외사업 담당자
- 여러 거래처와 이메일로 업무를 진행하는 사용자

### 4.2 Secondary User

- 일반 사무직
- 연구개발 담당자
- 프리랜서
- 투자 및 정부과제 담당자

## 5. 핵심 사용자 시나리오

사용자는 매일 많은 이메일을 받는다.

이메일에는 다음과 같은 업무가 포함될 수 있다.

- 회의 일정
- 자료 제출일
- 계약 일정
- PoC 일정
- 회신 요청
- 답변 기한
- 후속 조치 요청

현재 사용자는 메일을 직접 읽고 Outlook 또는 Google Calendar에 일정을 입력한다.

이 과정에서 시간이 소요되고 중요한 일정이나 회신 기한을 놓칠 수 있다.

사용자는 이메일 속 업무를 AI가 찾아 일정 후보로 보여주고, 자신이 확인한 일정만 캘린더에 등록되기를 원한다.

## 6. 핵심 가치 제안

사용자는 이메일을 모두 다시 읽거나 일정을 수동으로 입력하지 않고도 중요한 일정과 답변 기한을 관리할 수 있다.

## 7. MVP 핵심 기능

## 8. User Flow

### 단계 1. 이메일 계정 연결

화면에서 사용자는 Gmail 또는 Outlook 연결 버튼을 누르고 계정 접근을 승인한다.

사용자는 연결 성공 상태와 분석 가능한 이메일 범위를 본다.

### 단계 2. 이메일 분석

화면에서 사용자는 `메일 분석 시작` 버튼을 누른다.

사용자는 분석 중인 이메일 수, 진행 상태 및 오류 여부를 본다.

### 단계 3. 일정 후보 확인

화면에서 사용자는 이메일에서 추출된 일정과 답변 기한 후보를 검토하고 필요한 항목을 선택하거나 수정한다.

사용자는 날짜, 시간, 일정 종류, 발신자, 원본 메일 링크 및 `[확인 필요]` 상태를 본다.

### 단계 4. 캘린더 및 알림 등록

화면에서 사용자는 선택한 일정의 `등록` 버튼을 누른다.

사용자는 등록될 캘린더, 일정 내용 및 알림 정책을 확인한다.

### 단계 5. 완료 확인

화면에서 사용자는 캘린더 등록 완료 메시지와 Dashboard에 추가된 업무를 본다.

사용자는 중요한 일정과 답변 기한이 관리되고 있다는 상태를 확인한다.

## 9. 완료 기준

사용자가 이메일에서 추출된 일정과 답변 기한을 확인한 뒤 선택한 항목을 캘린더에 등록하고, 해당 업무가 Dashboard와 알림 목록에 정상적으로 표시되면 핵심 User Flow가 완료된 것으로 본다.

## 13. 비기능 요구사항

### 13.1 보안

- OAuth 기반 인증을 사용한다.
- 이메일 계정 비밀번호를 직접 저장하지 않는다.
- API 키와 토큰을 소스코드에 작성하지 않는다.
- 최소 권한 원칙을 적용한다.
- 로그에 이메일 본문이나 인증 토큰을 노출하지 않는다.

### 13.2 개인정보

- 메일 원문은 기능 제공에 필요한 범위를 넘어 저장하지 않는다.
- 저장이 필요한 경우 사용자에게 목적과 보존 기간을 알린다.
- 사용자는 연결 해제와 데이터 삭제를 요청할 수 있어야 한다.

세부 개인정보 처리 정책은 법률 및 운영 기준 검토가 필요하다. `[확인 필요]`

### 13.3 성능

초기 목표:

- 이메일 100개 분석 1분 이내 `[확인 필요]`
- 일정 후보 화면 응답 3초 이내 `[확인 필요]`
- 캘린더 등록 결과 5초 이내 `[확인 필요]`

실제 목표값은 기술 검증 후 확정한다.

### 13.4 정확성

초기 목표:

- 명시적인 날짜 추출 정확도 90% 이상 `[확인 필요]`
- 답변 기한 추출 정확도 85% 이상 `[확인 필요]`
- 불명확한 일정의 자동 확정률 0%

### 13.5 가용성

- 인증 및 외부 API 오류를 사용자에게 알린다.
- 실패한 이메일은 재분석할 수 있어야 한다.
- 일부 이메일 분석 실패가 전체 분석 실패로 이어지지 않도록 한다.
